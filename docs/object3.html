    Object3 — A Small S3-Compatible Object Store

    A from-scratch S3-compatible object store in Java 17 / Spring Boot / SQLite. Same REST protocol, same SigV4 (AWS4-HMAC-SHA256) auth, multipart uploads, versioning and byte-range downloads — so the AWS SDK, aws-cli or boto3 can talk to it just by overriding the endpoint URL.

    Two projects share one codebase: ObjectStoreDB (the S3 server) and AdminAPI (seeds users/permissions). They share one SQLite database placed next to both projects: PROJECT_URL/Object3/data.db.

    1.How a request travels through the system

    AWS SDK / aws-cli / boto3 — SigV4 signed HTTP request
    ▼
    AuthenticationFilter (authn + authz, every request)
    ▼ allowed?
    FileOperationController (REST endpoints)
    ▼
    FileOperationService → data/ on disk (buckets/…, multipart/…)
    ▼
    Repositories + SQLite (versions, objects, credentials, authorization)

    The filter runs before any controller: it authenticates the signature, then authorizes the operation.

    2.Authentication (SigV4 / AWS4-HMAC-SHA256)

    Every request carries an Authorization header proving it was signed with a valid secret key. Object3 recomputes the signature server-side and compares.

    Authorization: AWS4-HMAC-SHA256 Credential=test/20260830/us-east-1/s3/aws4_request, SignedHeaders=host;x-amz-content-sha256;x-amz-date, Signature=3f6c…

    The Credential= value is the signing scope, split by /:

    PartExampleMeaning
    Credential=testAccess key — looks up the secret key
    date20260830Date used to derive the signing key
    regionus-east-1AWS region
    services3must be s3
    terminatoraws4_requestmust be aws4_request

    2.1 The canonical request — the 6 ingredients

    A request is signed by building a canonical (normalized) request — six blocks joined by newlines:

    HTTP MethodGET/PUT/POST/DELETE/HEADbuildCanonicalRequest()
    Canonical URIURI with // collapsed to /canonicalUri()
    Canonical Query Stringparams sorted by name (values sorted), includes ?uploads, ?partNumber, ?uploadIdcanonicalQuery()
    Canonical Headerssigned headers lower-cased, trimmed, one per line name:valuerows 94–108
    Signed Headersthe SignedHeaders=… list sorted, joined by ;row 121
    Hashed Payloadhex SHA-256 of body, from x-amz-content-sha256rows 110–115
    private String buildCanonicalRequest(request, signedHeaders, omitEmptyEquals) throws Exception {
    String method        = request.getMethod();
    String canonicalUri   = canonicalUri(request.getRequestURI());
    String canonicalQuery = canonicalQuery(request.getQueryString(), omitEmptyEquals);

    TreeMap<String,String> headers = new TreeMap<>();          // sorted header map
    for (String name : signedHeaders.split(";")) {
        String h = name.trim().toLowerCase();
        if (!h.isEmpty()) headers.put(h, headerValue(request, h));
    }

    StringBuilder canonicalHeaders = new StringBuilder();
    for (entry : headers.entrySet())
        canonicalHeaders.append(key).append(':').append(value).append('\n');  // name:value\n

    String payloadHash = request.getHeader("x-amz-content-sha256");
    if (payloadHash == null || payloadHash.isEmpty())
        payloadHash = ("GET".equals(method) || "HEAD".equals(method) || "DELETE".equals(method))
                ? sha256Hex("")                                  // empty body
                : "UNSIGNED-PAYLOAD";                             // fallback

    return method + '\n' + canonicalUri + '\n' + canonicalQuery + '\n'
            + canonicalHeaders + '\n'
            + String.join(";", headers.keySet()) + '\n'          // SignedHeaders
            + payloadHash;                                               // Hashed Payload
}

    2.2 From canonical request to signature

    private boolean matches(signingKey, canonicalRequest, amzDate, dateStamp, region, provided) {
    String stringToSign = "AWS4-HMAC-SHA256\n"
            + amzDate + "\n"
            + dateStamp + "/" + region + "/" + SERVICE + "/" + TERMINATOR + "\n"
            + sha256Hex(canonicalRequest);
    byte[] signature = hmac(signingKey, stringToSign);

    return MessageDigest.isEqual(            // constant-time compare
            HexFormat.of().formatHex(signature).getBytes(),
            provided.getBytes());
}

private byte[] signingKey(secretKey, dateStamp, region) {        // 4 HMAC layers
    byte[] kDate    = hmac(("AWS4"+secretKey).getBytes(), dateStamp);
    byte[] kRegion  = hmac(kDate, region);
    byte[] kService = hmac(kRegion, SERVICE);        // "s3"
    return hmac(kService, TERMINATOR);            // "aws4_request"
}

    verify() derives the signing key once, then tries two canonical variants (with/without the empty =) to stay compatible with SDKs, and enforces a 15-minute clock skew:

    return Math.abs(System.currentTimeMillis() - requestTime) <= SKEW_MILLIS;  // 15 * 60 * 1000

    2.3 The filter — where it is wired in

    AuthenticationFilter (a OncePerRequestFilter) guards every request:

    String header = request.getHeader("Authorization");
if (header == null || !header.startsWith("AWS4-HMAC-SHA256"))
    { reject(response, "AccessDenied", "Missing or invalid Authorization header"); return; }

credential    = extract(header, "Credential=",   ",");
signedHeaders = extract(header, "SignedHeaders=", ",");
signature     = extract(header, "Signature=",    null);

parts = credential.split("/");                     // [key, date, region, s3, aws4_request]
if (parts.length != 5 || !"s3".equals(parts[3]) || !"aws4_request".equals(parts[4]))
    { reject(response, "AccessDenied", "Invalid credential scope"); return; }

ok = authService.authenticate(request, parts[0], signature, signedHeaders, parts[1], parts[2]);
if (!ok) { reject(response, "SignatureDoesNotMatch", "Signature verification failed"); return; }

    Errors are S3-style XML with HTTP 403:

    response.setStatus(403);  response.setContentType("application/xml");
response.getWriter().write("<Error><Code>" + code + "</Code><Message>" + message + "</Message></Error>");

    2.4 AuthenticationService

    Turns access key → secret key and delegates crypto:

    public boolean authenticate(request, accessKey, signature, signedHeaders, dateStamp, region) {
    Credential credential = repository.findByAccessKey(accessKey);
    if (credential == null) return false;                       // unknown key
    return signatureUtils.verify(request, credential.getSecretKey(),
            dateStamp, region, signedHeaders, signature);
}

    3.Authorization (permissions per user)

    Authentication answers “who are you?” — authorization answers “are you allowed to do this?”

    3.1 Data model

    TablePurpose
    credentialsaccess_key, secret_key, active
    permissionsread, write, delete, admin
    authorizationa pattern per user, e.g. * or pics/
    authorization_permissionmany-to-many link (authorization ↔ permission)

    Tables are created in AutoCreateTable and seeded with the default test/test user, pattern *, read/write/delete.

    3.2 The query — getAuthoritiesByUser

    SELECT c.access_key, a.pattern, p.authority
FROM authorization_permission ap
JOIN authorization a ON a.id = ap.authorization_id
JOIN permissions p    ON p.id = ap.permission_id
JOIN credentials c    ON c.id = a.user_id
WHERE c.access_key = ?
ORDER BY a.pattern                    -- grouped into one Authorization per pattern

    3.3 Decision — AuthorizationService

    public boolean isAuthorized(uri, accessKey, authority) {
    return repository.getAuthoritiesByUser(accessKey).stream()
            .anyMatch(auth -> auth.getAuthorities().contains(authority)
                    && matches(auth.getPattern(), uri));
}

public boolean matches(pattern, uri) {
    if (pattern.endsWith("*")) {
        String prefix = pattern.substring(0, pattern.length()-1);
        return uri.startsWith(prefix);          // "pics/*" → any prefix
    }
    return uri.equals(pattern) || uri.startsWith(pattern + "/");
}

    The filter maps method → authority and builds the resource path:

    String authority = switch (request.getMethod()) {
    case "GET", "HEAD"      -> "read";
    case "PUT", "POST"      -> "write";
    case "DELETE"           -> "delete";
    default               -> "";
};
String resource = bucket + (key.isEmpty() ? "" : "/" + key);
if (!authorizationService.isAuthorized(resource, accessKey, authority))
    { reject(response, "AccessDenied", "Not authorized for this operation on " + key); return; }

    5.Uploading objects

    5.1 Simple upload — PUT

    Path versionFile = objectDir.resolve(versionId);
InputStream in = ("aws-chunked".equalsIgnoreCase(request.getHeader("Content-Encoding")))
        ? new AwsChunkedInputStream(request.getInputStream())
        : request.getInputStream();

try (var out = Files.newOutputStream(versionFile, CREATE, TRUNCATE_EXISTING, WRITE)) {
    byte[] buf = new byte[8192]; int read;
    while ((read = in.read(buf)) != -1) out.write(buf, 0, read);
}

    5.2 Multipart upload — 4 steps (big files)

    MethodPath + queryWhat happens
    POST/{bucket}/**?uploadsstart → returns XML UploadId, creates parts folder
    PUT/{bucket}/**?partNumber=N&uploadId=Ustore part-N + .etag, returns ETag
    POST/{bucket}/**?uploadId=Uverify ETags, merge parts in order → version file
    DELETE/{bucket}/**?uploadId=Uabort — delete the parts folder

    Completion merges only listed parts, sorted by number, validating each ETag:

    for (entry : parts.entrySet().stream().sorted(byPartNumber)) {
    if (!Files.readString(etagPath).trim().equals(clientETag))
        throw new RuntimeException("ETag mismatch for part " + partNumber);
    try (InputStream in = Files.newInputStream(partPath)) { in.transferTo(out); }  // append
}

    5.3 aws-chunked bodies

    The AWS SDK streams signed bodies as Content-Encoding: aws-chunked — chunks of <hex-size>[;chunk-signature=…]\r\n payload \r\n, ending with 0\r\n\r\n.

    private void readNextChunkHeader() throws IOException {
    String header  = readLine();                          // e.g. "10000;chunk-signature=abc"
    String hexSize = header.split(";")[0];
    int size = Integer.parseInt(hexSize.trim(), 16);
    if (size == 0) { finished = true; readLine(); return; }   // final chunk
    remainingChunkBytes = size;
}

    5.4 Resumable upload — “skip parts that already exist”

    Each part lives in its own file + ETag marker. If the connection drops mid-part, the client re-sends that partNumber. And if the server already has the part, it short-circuits before writing anything:

    Path partPath = dir.resolve("part-" + partNumber);
Path etagPath = dir.resolve("part-" + partNumber + ".etag");

if (Files.exists(partPath) && Files.exists(etagPath)) {
    String existingEtag = Files.readString(etagPath).trim();
    log.info("Part " + partNumber + " already exists → skip re-upload (ETag: " + existingEtag + ")");

    try (InputStream skip = request.getInputStream()) {
        skip.transferTo(OutputStream.nullOutputStream());   // drain body, keep connection clean
    }
    return existingEtag;                                 // old ETag — do not touch the file
}

    Step by step:

    1. Builds paths for the part file and its .etag marker.
    2. Checks both exist — the ETag is written only after a full successful write, so a half-written part (crash mid-stream) is treated as missing and re-uploaded.
    3. Drains the incoming body to nullOutputStream() so Tomcat keeps the connection reusable.
    4. Returns the stored ETag → client sees 200 and completes normally.

    That is the full “continue from the last part” behaviour: parts are idempotent, re-sending one is harmless and fast.

    6.2 Range / resume downloads

    This is the download resume feature: the client asks for the byte offset where it stopped.

    range = range.replace("bytes=", "").trim();
String[] parts = range.split("-");

long start = Long.parseLong(parts[0]);
long end   = (parts.length > 1 && !parts[1].isEmpty()) ? Long.parseLong(parts[1]) : fileSize - 1;
long contentLength = end - start + 1;

RandomAccessFile raf = new RandomAccessFile(path.toFile(), "r");
raf.seek(start);                 // ← jump straight to the byte we stopped at

    A byte-limited stream wraps the RandomAccessFile, then the response is 206 Partial Content:

    return ResponseEntity.status(206)
        .header("Accept-Ranges", "bytes")
        .header("Content-Range", "bytes " + start + "-" + end + "/" + fileSize)
        .header("Content-Length", String.valueOf(contentLength))
        .body(new InputStreamResource(limitedStream));

    A client that lost the connection resumes with Range: bytes=<count>-; the server seeks to that byte with raf.seek(start) and continues from exactly there.

    8.Function-by-function reference — the service package

    AuthenticationService

    FunctionWhat it does
    authenticate(request, accessKey, signature, signedHeaders, dateStamp, region) Loads the secret key for accessKey (unknown → false), then verifies the SigV4 signature via SignatureUtils.verify.

    AuthorizationService

    FunctionWhat it does
    isAuthorized(uri, accessKey, authority)Loads the user’s (pattern, authorities) rows and returns true if any pattern contains the required authority and matches the resource.
    matches(pattern, uri)*-suffixed → prefix match; otherwise exact or path-prefix match.

    FileOperationService

    FunctionWhat it does
    init()@PostConstruct — resolves root from the ${data} property.
    startMultipart(request, bucket)Creates data/multipart/<bucket>/<key>/<uploadId> (random UUID) and returns the S3 initiate XML with the UploadId.
    uploadPart(request, bucket, partNumber, uploadId)Stores one part (raw or aws-chunked), computes MD5 → part-N.etag, returns ETag. Resume guard: if part+etag already exist it drains the body and returns the stored ETag.
    completeUpload(request, bucket, xml)Parses the completion XML, merges listed parts in order (ETag-checked) into a new versionId, records version + metadata, returns completion XML + version id.
    AbortMultipartFileUpload(request, bucket)Deletes the multipart folder recursively (abort).
    UploadFileInOneShot(request, bucket)Simple PUT — writes whole body to objects/<key>/<versionId>, records metadata, returns version id.
    downloadFile(request, bucket)Serves GET — full 200, or 206 Partial Content for a Range header using RandomAccessFile.seek.
    deleteFile(request, bucket)Soft-delete: marks version deleted=1, removes the file.
    getObjectHeaders(request, bucket)Backs HEAD — returns stored metadata (content-type, size, version id).

    Helpers those services rely on

    • SignatureUtils.verify → buildCanonicalRequest, matches, signingKey, withinSkew, canonicalQuery, canonicalUri, headerValue, normalize, hmac, sha256Hex.
    • FileUtils.extractKey strips /bucket/ from the URI; extractPartsFromXML parses completion XML; bytesToHex formats digests.
    • AwsChunkedInputStream — read(), readNextChunkHeader(), readLine().

    12.Known behaviours & caveats

    • ../data.db is relative to the working directory — start each app from its own folder, otherwise you get SQLITE_CANTOPEN.
    • Simple uploads are not byte-resumable — use multipart for big files (that is where per-part resume lives).
    • completeUpload stores request.getContentLengthLong() from the completion request, not the object size.
    • Signatures compare in constant time (MessageDigest.isEqual) with a 15-minute clock-skew window.
